# TrustMatrix AI

AI-Powered Digital Trust & Fraud Intelligence Platform

## Overview
TrustMatrix AI is an intelligent platform designed to detect online scams, phishing attacks, fake news, and digital fraud using advanced AI technologies.

## AI Technologies
- Large Language Models (LLM)
- Retrieval-Augmented Generation (RAG)
- AI Agents
- Multimodal AI
- Explainable AI (XAI)
- Semantic Search

## Features
- Scam & phishing detection
- Website verification
- QR code security analysis
- Fake news detection
- Image/document analysis
- AI risk scoring
- Explainable fraud reports
- Bangla & English support

## Tech Stack
Frontend:
React.js

Backend:
Node.js + Express.js

Database:
MySQL

AI:
LLM API + RAG + Vector Database
